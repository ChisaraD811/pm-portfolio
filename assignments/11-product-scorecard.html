Product Scorecard

North Star metric and success framework for Book Clubs

Apple Books · iMessage Book Clubs McCombs PM Course Assignment 11

This scorecard evaluates the iMessage Book Clubs feature across four product health dimensions: Desirability, Usability, Adoptability, and Business Value. It is anchored to the North Star Metric: Weekly Active Club Readers.

Part 1 - North Star Metric

North Star Metric
Weekly Active Club Readers
Users who both read at least 10 minutes AND send or react to a club message within the same 7-day window.
Why it matters: The dual condition keeps the metric honest - a user who only chats hasn't built a reading habit; a user who reads but never engages hasn't experienced the social accountability the feature is designed to create.

Part 2 - Supporting Metrics

🏁
Activation
New Clubs Created / Week

Tracks whether users discover and activate the feature. A club must exist before any engagement can happen.

🤝
Acquisition
Invite Acceptance Rate

% of iMessage club invitations accepted. Measures how well the feature converts existing social graphs into co-readers.

📖
Reading Engagement
Avg. Reading Min / Member / Week

Confirms the feature drives the core behavior - reading - not just chat. Ensures the social layer lifts reading, not replaces it.

💬
Social Engagement
Discussions / Active Club / Week

Messages, reactions, and polls sent per club. A proxy for how much the feature adds value beyond solo reading.

Part 3 - UX Health Scorecard

Dimension Description Current State Target State
Desirability Do users want this feature? High - In-App Book Clubs ranked as Excitement/Delight in Kano analysis, top of satisfaction curve Maintain excitement classification post-launch; track Kano re-surveys at 6 months
Usability Can users complete the core flow without friction? To be validated - prototype tested conceptually; no live usability data yet <3 taps to create a club; 0 support tickets for core flow in first 30 days
Adoptability How easily can users discover and start using it? Entry point identified (Home tab Book Clubs section); invite via iMessage reduces cold-start Invite acceptance rate >40%; 1,000 clubs created in beta week 1
Business Value Does it support Apple's goals? Feature directly addresses engagement, differentiation, and ecosystem stickiness goals from PRD 20% engagement lift; 10% book purchase uplift via club-driven social discovery

Part 4 - Early Warning System

Early Warning System

Each supporting metric (clubs created, invite acceptance rate, reading minutes per member, discussions per active club) feeds directly into Weekly Active Club Readers. A drop in any one of them surfaces in the NSM before it appears in revenue or churn data - giving the team time to act.
