## Deploying to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Under "Source" select: **Deploy from a branch → main → / (root)**
4. Click Save. Your site will be live at `https://[your-username].github.io/[repo-name]/`

## Adding Your Assignment Images

Place your image files in `/assets/images/` with these exact filenames:

- `01-business-model-canvas.jpg`
- `02-value-proposition-canvas.jpg`
- `03-product-vision-board.jpg`
- `04-opportunity-solution-tree.jpg`
- `08-kano-analysis.jpg`
- `09-roadmap.jpg`
- `10a-prototype-screens-1.jpg`
- `10a-prototype-screens-2.jpg`

**Recommended:** Export your PDFs as JPG at 2x resolution for sharpness. On Mac: open PDF in Preview → File → Export → JPEG → 150dpi.
